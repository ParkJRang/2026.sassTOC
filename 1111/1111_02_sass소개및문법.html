02_sass소개 및 문법

SASS - Syntatically Awesome StyleSheets의 줄임말

SCSS - Sassy css의 줄임말

CSS pre-prorcessor(전처리기)로서 css반복을 줄여서 시간을 절약할 수 있도록 해주는 css언어의 확장언어

css를 좀 더 효율적으로 작성하고 유지보수하기 쉽게 만들어줌

장점 : 변수 및 조건문 등 새로운 문법을 통해 css를 구조화하여 작업 가능

단점 : 코드가 지저분해질 수 있음, 코드가 많아질수록 유지보수 어려움

프로그램 설치는 sass공식사이트에서 gui, cli 방식의 프로그램들 중 자신이 편한 프로그램을 다운받아 설치

vscode에서는 별도 확장프로그램(live sass complier)을 지원하기 때문에 왼쪽 확장자 메뉴 아이콘 클릭하여 설치 후 사용

1. sass, scss문법 차이점

sass문법
중괄호({})와 세미콜론(;) 필요없음
들여쓰기(tab키)를 사용하여 코드 구조 나타냄
구문이 더 간결하고 Python스타일과 비슷함
    sass 작성 예시)
    $primary-color:#3498db;
    body
      background:$primary-color;
      color:#fff;

    nav
      ul 
        margin:0;
        padding:0;
        li
          list-style:none;
          margin-right:10px;
scss문법
css문법과 유사함
중괄호({})와 세미콜론(;) 사용
기존 css와 호환성 높음
    scss 작성 예시)
    $primary-color:#3498db;
    body{
      background:$primary-color;
      color:#fff;
    }
    nav{
      ul{
        margin:0;
        padding:0;
        list-style:none;
        li{
          list-style:none;
          margin-right:10px;
        }
      }
    }

2. 둘 중 어느것을 작성하는게 좋은가?

scss 권장:
css와 문법이 유사하여 기존 css파일과 통합하기 쉬움
팀원들이 css에 익숙하다면 scss 사용이 더 용이함
최신 문법과 기능이 주로 scss에서 지원되며, sass는 유지 보수용으로만 사용됨
sass 공식 문서에서도 scss 사용 권장
sass 사용이유:
더 간결한 문법을 선호하거나, 기존 sass 스타일을 유지해야 하는 프로젝트에서 유리함
결론
scss 사용이 더 권장됨
더 널리 사용되며, 유지보수 및 협업에 유리함
최신 기능 지원 및 css와의 호환성도 더 높음
