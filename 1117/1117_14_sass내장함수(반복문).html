1. @for문

@for 키워드는 '스타일을 반복적'으로 출력하는데 사용됨

javascript의 for문과 유사함

    문법1)
    trough : 종료 만큼 반복
    @for $변수 from 시작 through 종료{
      //반복할 내용
    }

    문법2)
    to : 종료 전까지 반복
    @for $변수 from to 종료{
      //반복할 내용
    }

$변수 => #{변수}

#{변수}는 코드 어디든지 변수 값 적용 가능

ex) $img:unquote('./img/#{$img}');

h1{background-image:url('./img/#{$img}');}

    @while 조건식{
      //반복할 내용
    }
    //js에서의 while문 2가지
    방법1.
