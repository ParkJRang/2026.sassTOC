sass의 mixin기법과 include기법에 대해 학습하기

1. $mixin기법

웹사이트 전체에 재사용할 css코드를 정의하는 문

    @mixin mixin명{
      //반복해서 사용할 스타일 서식을 작성
    }

2. @include기법

@mixin을 선택자에 포함하는데 사용하는 지시문

    css선택자{
      @include mixin명;
    }

03. @mixin 중첩사용

      @mixin 믹스인명 A{
        //재사용할 스타일 서식 작성
      }
      @mixin 믹스인명 B{
        //재사용할 스타일 서식 작성
      }
      @mixin 믹스인명 C{
        @include 믹스인명 A;
        @include 믹스인명 B;
      }
