1. SNS아이콘(페북, X, 익스타, 카카오, 네이버) 삽입하여 믹스인 문법으로 서식 적용

2. 믹스인 문법의 매개변수 사용법

@mixin는 js의 함수처럼 매개변수와 인수값을 가질 수 있음

매개변수를 사용하영 다양한 결과물을 구현할 수 있음

    문법)
    mixin 믹스인명($매개변수...){
      //재사용할 스타일 서식
    }
    @include 믹스인명(인수)

box02

@mixin에 매개변수 여러개 만들어서 값 적용 가능

실습2. 로그인 네이버, 카카오 로그인 버튼 만들고 @mixin함수와 매개변수 활용하여 서식 적용

@mixin에 매개변수 기본값 설정

매개변수는 기본값을 가질 수 있음. @include에서 별도의 인수를 전달하지 않으면 기본값으로 사용됨

    문법)
    @mixin 믹스인명($매개변수:기본값){
      //적용하고자 하는 css서식;
    }

실습3. 목록태그를 작성하여 목록별 테두리 서식을 각각 다르게 설정

  • 실선(기본값)으로 테두리 적용
  • 굵은선(3px)으로 테두리 적용
  • 이중선(double)으로 테두리 적용
  • 점선(dotted)으로 테두리 적용
  • 점선(dashed)으로 테두리 적용
